# Northstar Support Deflection MVP

## Group 21

## Problem

Northstar Retail Co. receives repetitive support requests
related to order status and returns/refunds.

## Solution

Our Support Deflection MVP allows customers to resolve
common support questions without immediately contacting
a support agent.

## Supported Ticket Types

- Order Status
- Returns & Refunds

## MVP Features

- Order status lookup
- Return information
- Refund information
- Customer support navigation

## Technology

- HTML
- CSS
- JavaScript
